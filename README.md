# Prospection cabinets médicaux

Outil de prospection téléphonique pour vendre des automatisations IA aux cabinets médicaux.
Un seul fichier autonome : ouvrez `index.html` dans un navigateur, aucune installation.

- Tableau de bord, base cabinets, fiche en mode appel (script, objections, calculateur de gains, historique, prochaine action), pipeline, relances, statistiques, paramètres.
- Données enregistrées dans le stockage local du navigateur ; import et export CSV dans Paramètres.
- Raccourcis en mode appel : `1` à `7` pour le résultat, `D` pour démarrer ou arrêter le chronomètre, `Ctrl + Entrée` pour enregistrer et passer au suivant.
