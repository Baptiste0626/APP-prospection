# Prospection cabinet

Outil interne d’un cabinet médical, avec des automatisations IA intégrées. L’IA prépare, l’humain valide : aucune décision médicale n’est prise par l’IA.
Un seul fichier autonome : ouvrez `index.html` dans un navigateur, aucune installation.

- Profils : Gérant, Médecin, Secrétaire / assistant (sélecteur en haut du menu). Le menu et le tableau de bord s’adaptent au profil.
- Modules : tableau de bord, agenda, patients, secrétariat IA (journal des appels et traitement des rappels), demandes patients, comptes rendus, documents, modèles de réponses. Activité, Automatisations et Équipe sont réservés au gérant.
- Données enregistrées dans le stockage local du navigateur ; import et export CSV des patients dans Paramètres. Toutes les données d’exemple sont fictives.
- Raccourcis dans le secrétariat IA : `1` à `5` pour traiter l’appel sélectionné, `Ctrl + Entrée` pour enregistrer et passer au suivant.
